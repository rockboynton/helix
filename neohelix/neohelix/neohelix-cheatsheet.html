Neohelix

Neohelix review cheat sheet

For actions paired with expected results and disposable fixtures, use the acceptance walkthrough.

See the optional user keymap and short command aliases for the author’s Space g and z f menus. Tables below also include fork defaults.

Start a review

hx --review                         # Git HEAD / JJ parent vs working copy
hx --review before-dir after-dir    # Full directory changeset
hx --diff before.rs after.rs        # Two editable source files
hx --diff3 left.rs base.rs right.rs  # Three editable files, base in the middle
hx --diff --diff-layout inline before.rs after.rs
git diff | hx --patch
jj diff --color-words --color never | hx --patch

File paths select the normal Helix language/Tree-sitter configuration. Patches accept Git unified and native JJ markers, are read-only, and never open paths named inside the patch. Inline file/review views edit the real working document; deleted baseline rows are virtual and read-only. --pager makes file inputs read-only.

Transfers are undoable and never save automatically. Review baselines cannot be edited; working text can. In three-way mode, transfers compare the focused outer pane with base. Choose an outer pane before transferring.

diff-off keeps the working file in the leftmost comparison pane, closes the extra comparison panes, and restores the sidebar that preceded the review. Buffers and unsaved edits remain available. In three-way mode it keeps the focused outer variant (right if base was focused). Unrelated panes remain open.

Split comparisons reuse existing adjacent columns rather than accumulating panes. File changes refresh reviews automatically when watching is enabled: catalog updates are debounced, clean files reload, and dirty buffers are retained. Piped patches are immutable snapshots. Manual refresh is still useful if native watching is disabled or unavailable.

Sidebar navigation

/ edits a live, case-insensitive name/path substring filter. Matching files remain in their hierarchy with ancestors revealed; Enter keeps the filter, then opens the selected file on the next press. n/p (or N backwards) wrap through matches without switching the review file. Esc cancels an edit, clears an accepted filter, then returns to the editor on a subsequent press. Backspace edits a grapheme; Ctrl-u clears the input and Ctrl-w deletes a word. H/L collapse/expand all; PageUp/PageDown and Ctrl-u/Ctrl-d navigate pages and half-pages outside filter input. ? shows a key summary. Clearing the filter restores browsing expansion; refresh retains the query and selection.

j / k select; h collapses or goes to parent; l expands; Enter opens a file or toggles a directory. g / G select first / last. Tab or Escape returns to editing. r refreshes ordinary/Git trees, but reopens the revision picker in a JJ review. Without a filter, review-tree n / p change file and v toggles layout. :file-tree-close closes the sidebar without closing documents.

Colors and word changes

Diffs keep normal Helix gutter icons and syntax foreground colors. Muted line backgrounds show additions/removals; stronger word backgrounds emphasize changed tokens within replacement blocks. This works in split, inline, three-way and patch views. Large replacement blocks fall back to line-only coloring.

Theme overrides: ui.diff.minus, ui.diff.plus, ui.diff.minus.word, ui.diff.plus.word (set bg, not the syntax foreground). Word highlighting is textual, not a compiler-semantic analysis.

Picker readability

The active diagnostic message wraps within its picker column instead of being hidden behind the preview. Alt-] / Alt-[ scroll long messages; moving to a different diagnostic resets the scroll. File previews show a loading state until asynchronous Tree-sitter highlighting resolves, with plaintext fallback if no parser is available.

PNG/PDF picker previews work in direct Ghostty/Kitty sessions. PDFs require pdftoppm; Alt-j / Alt-k change pages. See media previews for limits and current multiplexer support.

GitLens

:blame-toggle shows/hides a full-file commit/date/author strip to the left of the focused buffer, independently of the file tree and popup. The author’s config binds it to Space g b. Metadata loads asynchronously; no GitHub token is needed for these local annotations.

With your Space B binding, open on-demand blame details without continuously rendering inline blame. Within the popup:

PR lookups use native Octocrab HTTP requests with GitHub Enterprise host support. Environment tokens are checked before saved gh credentials / native credential storage. For custom Enterprise hosts use GH_ENTERPRISE_TOKEN or GITHUB_ENTERPRISE_TOKEN; GitHub.com uses GH_TOKEN or GITHUB_TOKEN. Native access to a token saved by gh can trigger a macOS Keychain permission prompt for hx. Local blame still works without API authentication. Do not put tokens in version-controlled config. See token creation and required permissions for GitHub/Enterprise setup and the Keychain-free launch instructions.

Render output for jjui / other pagers

--render-diff writes read-only formatted output, not an embedded interactive Helix terminal. It supports inline / side-by-side layouts and patch input; the host controls navigation. See the full file-diff guide for its width, context and color flags and the changeset guide for review boundaries. Native historical JJ revision selection is available through :jj-review; a persistent revision graph, staging and full semantic changeset analysis are not implemented.

With JJ configured to use the neohelix tool, jj diffedit -r REV opens editable multi-file review. In jjui, Shift-E uses that same diff editor and returns to jjui on exit. Save in Helix first; JJ imports the saved right-side files and may rewrite the selected revision/rebase descendants. See the JJ/jjui setup.

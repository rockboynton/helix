# Neohelix

Documentation for the `neohelix` development branch of
[rockboynton/helix](https://github.com/rockboynton/helix), not upstream Helix's
stable release. Start with the [Neohelix guides](./neohelix/index.md) for fork
features, configuration, examples and current limits. The remaining chapters
document the Helix editing model and supported configuration.

See the [usage] section for a quick overview of the editor, [keymap]
section for all available keybindings and the [configuration] section
for defining custom keybindings, setting themes, etc.
For everything else (e.g., how to install supported language servers), see the [Helix Wiki].

Refer the [FAQ] for common questions.

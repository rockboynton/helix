# Neohelix

This book documents Neohelix: Helix's editing model plus this fork's native
diff/review tools, Steel configuration and plugins, Jujutsu support, file watching,
folding, media previews and shared language servers.

Start with the [acceptance walkthrough](test-plan.md) to try features and check
expected behavior, or the [review cheat sheet](neohelix-cheatsheet.md) for quick commands. See the guides in
this section. The [optional user keymap](keybindings.md) describes the author's
bindings, not just built-in defaults. The generated [command reference](../commands.md)
reflects commands compiled into this fork.

The [feature inventory](https://github.com/rockboynton/helix/blob/neohelix/NEOHELIX.md)
explains the fork's rationale and PR provenance. The [development queue](roadmap.md)
separates available features from unfinished work. Guides state read-only/editable
boundaries, cache/worker defaults and platform validation limits explicitly.

Most usage/configuration chapters retain upstream Helix material. Use the
[Steel guide](steel.md) alongside the existing TOML reference. There is no
requirement to migrate a working TOML configuration.
